## Objective

Measure, using **real generated OTBM Atlas detail chunks**, whether lossless WebP materially reduces storage compared with the Atlas's current PNG representation while preserving decoded RGBA pixels exactly.

Produce:

1. machine-readable benchmark results;
2. a concise human-readable report;
3. representative PNG/WebP pairs for owner visual comparison;
4. an easy local HTML comparison page.

No implementation decision is authorized.

## Scope

Primary comparison:

- CURRENT PNG files exactly as generated by OTBM Atlas;
- WebP **lossless**.

Optional diagnostic comparison, only if locally supported without installing large/untrusted dependencies:

- re-encoded optimized PNG.

Do **not** use lossy WebP.

Do not use an AVIF configuration unless you can first prove decoded RGBA equality. AVIF is not required.

Main question:

> How much smaller would the real canonical detail atlas be if its existing PNG chunks were stored as WebP lossless while decoding to exactly the same RGBA pixels?

## Sample selection

Benchmark at least **200 real detailed Atlas chunks**, or all chunks if testing all of them is cheap enough.

The sample must not consist only of nearby files.

Use a deterministic, reproducible selection covering:

- as many `Z` floors as possible;
- very small PNG chunks;
- median-sized chunks;
- very large PNG chunks;
- several chunks from each size quartile;
- deterministic evenly distributed samples across the complete sorted chunk list.

Record the exact selected paths.

Avoid duplicates.

## Encoding requirements

For each tested chunk:

### Baseline

Use the existing PNG file byte-for-byte as the baseline. Do not re-encode it and call that the baseline.

Record:

- path;
- floor;
- dimensions;
- existing PNG bytes.

### WebP

Decode the PNG to RGBA.

Encode WebP using a **genuinely lossless mode**.

Record exact encoder/library/version and exact parameters.

Then decode the WebP back to RGBA.

Require:

- same width;
- same height;
- same number of channels;
- byte-for-byte RGBA equality.

For every tested WebP:

`decoded_webp_rgba == decoded_original_png_rgba`

must be true.

If a single tested image fails exact RGBA equality, report the failure prominently and do not describe that configuration as canonical-safe.
